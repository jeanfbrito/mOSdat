mOSdat - Multi-OS Desktop App Testing with GPU passthrough

positional arguments:
  {run,test,functional,confirm,validate,list-vms,report,dashboard,live,build,author,draft,preflight,replay,vlm-cache,lint,trace,atspi-dump,doctor,visual,recipes,routines}
    run                 Full test matrix run
    test                Quick test with pre-built package
    functional          Run VLM functional UI tests
    confirm             Confirm or verify-fix a tracked GitHub issue via a
                        bug-confirmation scenario
    validate            Validate config file
    list-vms            Show configured VMs
    report              Regenerate report from existing results or generate
                        flakiness leaderboard
    dashboard           H2.2: Generate static HTML trend dashboard from
                        functional runs
    live                Live event-stream dashboard — stream smoke test events
                        in real time
    build               I3: clone a PR, build the Electron app, deploy +
                        verify on VMs
    author              Agent client for the live authoring API
    draft               Generate functional test scenario YAML from change
                        descriptions
    preflight           I2: pre-run health checks for a functional scenario
    replay              Rerun a VLM verify against a cached result-dir
                        screenshot
    vlm-cache           I6: Manage the VLM verify result cache
    lint                F1a: Static analyzer for functional scenario YAML
                        files
    trace               F1b: Probe input capabilities (menu accelerators,
                        shortcuts, focus) on a VM
    atspi-dump          Print the live AT-SPI accessibility tree of a target
                        VM
    doctor              I13: Check VM and host health (SSH, deps, disk,
                        processes)
    visual              Visual regression: capture or check step screenshots
                        via SSIM
    recipes             F2: Browse known platform constraints and workarounds
    routines            R1: Browse and inspect reusable routine library

options:
  -h, --help            show this help message and exit
